# آزمون تعیین نوع ذهن (بر اساس نظریه هوش‌های چندگانه)

این پروژه یک ابزار تعاملی برای شناسایی نیمرخ ذهنی دانش‌آموزان بر اساس **نظریه هوش‌های چندگانه گاردنر** است. با پاسخ دادن به ۳۰ سؤال، شش بعد ذهنی شما سنجیده شده و نوع ذهن غالب همراه با درصد هر یک نمایش داده می‌شود.

## ویژگی‌ها
- **۶ بعد ذهنی**: تحلیلی (منطقی-ریاضی)، خلاق (هنری-تخیلی)، عملی (بدنی-اجرایی)، اجتماعی (ارتباطی-بین‌فردی)، درون‌گرا (تأملی-درون‌فردی)، طبیعت‌گرا.
- **پرسشنامه ۳۰ سؤالی** با مقیاس پاسخ ۲۵، ۵۰، ۷۵، ۱۰۰.
- **محاسبات پیشرفته** با استفاده از کتابخانه `numpy` شامل مجموع، میانگین، انحراف معیار و نرمال‌سازی درصدی.
- **خروجی readable** شامل نوع(های) غالب و درصد هر بعد.
- قابلیت توسعه و تحلیل‌های آماری بیشتر.


### پیش‌نیازها 
- python
- numpy
- colorama

### مراحل نصب 
- pip install numpy
- pip install colorama

### نحوه استفاده
- فایل اصلی پروژه main.py در دایرکتوری ریشه قرار دارد. آن را اجرا کنید:
- python3 main.py

### فرمول‌های محاسباتی

    نمره خام هر بعد = مجموع نمرات ۵ سؤال مربوطه (محدوده ۱۲۵ تا ۵۰۰).

    درصد نهایی هر بعد = (نمره خام - 125) / (500 - 125) * 100.

    نوع ذهن غالب = بعدی با بیشترین نمره خام (در صورت تساوی، چند نوع غالب اعلام می‌شود).

    میانگین و انحراف معیار برای نمایش پراکندگی پاسخ‌ها در هر بعد محاسبه می‌شود.
